Phase 4: Standalone Migration

Converted all 23 NgModules to standalone components using ts-morph AST transformation. Each component received its own imports array. All @NgModule declarations were removed. Routing modules replaced with standalone route configs using loadComponent. This was the most file-intensive phase (68 files).

Issue encountered: 3 components had circular imports through their NgModule. Resolved by extracting shared models to a separate file and using import type for interfaces.

Phase 5: Control Flow (@if/@for)

Migrated all structural directive syntax to Angular's built-in control flow. Ran the Angular schematic ng generate @angular/core:control-flow which handled 89% of conversions automatically. Remaining 11% (14 templates) required manual adjustment for complex *ngIf...else patterns with multiple template refs.

Issue encountered: @for requires a track expression. Added track item.id for all entity loops. For 5 loops without stable IDs, used track $index with a code comment noting this should be improved.

Phase 6: Signals Migration

Converted component state from BehaviorSubject to Angular Signals where applicable. Used signal() for local state, computed() for derived state, and effect() for side effects. Converted @Input() to input() and @Output() to output() where straightforward.
